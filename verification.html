How STARCITY Checks Its Work

Verification log · Last updated November 21, 2026

STARCITY is built by one person with AI assistance. AI makes it fast to pull public data and add it up. It does not make the result right. This page shows how each paper was checked, what the checks found, and what was corrected, so you can judge the work for yourself and do the same in your own city.

The process

  1. Start from the original record. Every figure comes from a file a government agency publishes, downloaded on a stated date. Nothing is carried from memory or from a news summary.
  2. Publish the method and the script. Each paper says how its numbers were computed and what they leave out. The code is in the project's public repository, so anyone can run it again.
  3. Look for an official figure that should agree. Before trusting a number, find the same quantity measured by someone else, usually a state agency. If they differ, find out why, and print both.
  4. Look for independent reporting. Where newsrooms have covered the same records, check that the names and amounts match.
  5. Say what is not verified. If no outside figure exists, or a gap is unexplained, the paper says so.
  6. Correct in public. Mistakes are fixed in the paper and listed below with the date.

Why this is hard

  • A number can be computed correctly and still mislead. Our assessment figure was right arithmetic. The error was not knowing the state already publishes the official measure.
  • Public data has traps. Lincoln's city limits layer holds 70 shapes with the same name. Map layers report areas about 75% too large at this latitude. State files repeat records from year to year. Each produces a wrong answer that looks reasonable.
  • Checking takes people who know the subject. A county assessor, a floodplain manager or a campaign treasurer can spot in a minute what a script never will.

What has not been done yet

  • No paper has been reviewed by the agency whose data it uses, or by an outside expert.
  • The figures on the map itself, outside the papers, have been checked less than the papers.
  • Updates are still made by hand, so a figure can go stale without notice. Each one carries its date for that reason.

Check it yourself, or check your own city

  1. Pick one number from any paper and open the source listed at the bottom of that paper.
  2. Find the same number, or the rows it was added up from.
  3. If it does not match, report it on the project's issues page. It will be checked and, if wrong, corrected here with the date.
  4. To do this for another Nebraska city, the state's files for assessment, TIF and campaign finance cover every county and city in the same format. The scripts in the repository are a starting point.
