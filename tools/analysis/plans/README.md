# City plans
`build.py` packs Lincoln open data planning layers into `data/plans.json`: Transportation Improvement Program
projects, planning applications since 2020, approved developments with homes still to build, PlanForward 2050
land use and growth tiers, annexations by decade, airport noise contours, historic districts and sites.
Staff names are dropped. Zoning appeals, waivers and administrative amendments keep no project name.
