STARCITY · any city

Type a place, a ZIP code or a GPS point and see it in 3D, built in your browser from OpenStreetMap, the free map of the world that volunteers keep.

Nothing is installed and nothing is stored. Buildings, streets, parks, water and trees come from OSM, so the picture is as complete as local mappers have made it.

This is the open, any-city version of STARCITY, a 3D map of Lincoln, Nebraska built from that city's own public records. The code is free to copy under the MIT license: github.com/RobotWhiteBread/STARCITY
